# StudySphere Features

The `/features` folder contains all the independent, modular components that make up the functionality of StudySphere. Each feature is segregated into its own directory, allowing for focused development, testing, and deployment.

## How to Use

To explore any specific feature and understand how it works or how to contribute, head to the relevant feature folder and read the `README.md` file located within each directory. Each feature contains detailed instructions for setup, usage, testing, and contribution.

Each feature's `README.md` provides all necessary information on how to run or test the feature independently of the rest of the application.

For further details, navigate to the specific feature folder and refer to the respective documentation.
